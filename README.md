# Flutter Lab 8 - Animations Demo

## Aim
To demonstrate Fade, Slide, Scale, Rotation, and Combined
animations using Flutter's animation framework.

## Animations Implemented
1. Fade Animation
2. Slide Animation
3. Scale Animation
4. Rotation Animation
5. Combined Fade and Slide Animation

## Features
- Interactive animation controls
- Smooth transitions
- Bounce scale effect
- 360-degree rotation
- Reset All Animations button
- Responsive user interface

## Technologies Used
- Flutter
- Dart
- Material Design

## Output
Screenshots of the application are available in the outputs folder.

## How to Run
1. Install Flutter SDK.
2. Open the project folder in VS Code.
3. Run flutter pub get.
4. Run flutter run -d chrome.
